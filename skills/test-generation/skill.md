# Test Generation Skill

## Purpose

Generate BDD scenarios and automated tests from test analysis.

## Inputs

- Test analysis
- Feature specification
- Acceptance criteria

## Actions

- Generate Gherkin scenarios
- Generate TypeScript test code
- Use Playwright for API automation
- Align tests with acceptance criteria
- Avoid testing unspecified behavior

## Output

- Gherkin scenarios
- TypeScript Playwright tests
- Required test data
