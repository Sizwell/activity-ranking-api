# Test Analysis Skill

## Purpose

Analyze a feature specification and identify what needs to be tested.

## Inputs

- Feature ticket
- Acceptance criteria
- Existing test information, when available

## Actions

- Extract functional requirements
- Identify positive scenarios
- Identify negative scenarios
- Identify edge cases
- Identify risks
- Identify dependencies
- Identify required test data

## Output

Produce structured test-analysis information that can be consumed by the Test Generator.
